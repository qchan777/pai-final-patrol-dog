# patrol-dog — 災害時の見回りを自律で行う四足ロボット (Physical AI 応用1 最終課題)

GPU 並列の物理シミュレータ Genesis 上の四足ロボット **Unitree Go2** が、倒壊した屋外を見立てた現場を **人の指示は最初の一回だけで** 見回ります。

- 歩く・転んでも起きる: **強化学習** (4,096 体並列、1 回の学習は 30 秒〜6 分)
- どこへ行くか: GPS (ばらつきあり) の経由地と、既知の地図 (壁・瓦礫の山) を避ける **A\* 経路計画**
- 見えない段差: 前方の **高さスキャナ** (LiDAR の見立て) で事前に迂回
- 要救助者: 頭のカメラで 360° 見回し、ローカルの **画像言語モデル (VLM)** に「人の形をした物体」を聞く → **人に YES/NO で確認** → 近づいて位置を通報
- 余震 (横からの衝撃) で転んでも、地形の上で起き上がって続行

## 何がどう動くか (一手の流れ)

```
GPS (1 Hz, ±1.5 m) ─┐
                    ├→ A* で経路 → 1.3 m 先の点へ速度・旋回の指令 ─→ 歩行方策 (RL) ─→ 12 関節
高さスキャナ (前方) ─┘   未知の段差があれば空いている向きへ
転倒を検知 ─→ 起き上がり方策 (RL) ─→ 0.5 秒立てたら歩行へ戻す (8 秒立てなければ体勢を変える)
経由地に到着 ─→ 頭のカメラ 8 方向 → VLM 「人の形をした物体は?」→ はい → 人に「近づきますか?」→ はい → 1.2 m まで近づき位置を通報 → 来た道を戻る
```

AI の役割分担: 反射 (転倒、進めない、段差) は規則で速く確実に、歩行と起き上がりは強化学習で、
認識と人との対話は VLM/LLM で。「全部を言語モデルに任せない」のは災害現場向けの実用上の判断です。

## 成績

### 見回り任務 (seed 8 通り、余震あり)

| seed | 結果 | 所要時間 | 転倒 (すべて自力復帰) | 人形の発見 → 通報 |
|---|---|---|---|---|
| 1 | 完了 | 156 秒 | 3 | 1 |
| 2 | 完了 | 177 秒 | 3 | 1 |
| 3 | 最終地点 (帰還) の手前で 320 秒切れ | — | 1 | 1 |
| 4 | 完了 | 170 秒 | 3 | 1 |
| 5 | 完了 | 122 秒 | 3 | 1 (遠方でも 1 回記録) |
| 6 | 完了 | 100 秒 | 1 | 1 |
| 7 | 完了 | 219 秒 | 1 | 1 |
| 8 | 完了 | 130 秒 | 1 | 1 |

**完了 7/8、発見と通報 8/8、転倒 16 回はすべて自力で復帰** (余震は全試行で 40 秒に横から 2.5 m/s)。
同じ試験は改良のたびに回し、完了率は 4/8 (回転中の足踏み) → 2/4 (はまり込み) → 8/8 だが発見 0 (人形が地面に埋没) → 5/8 (同じ人形に何度も近づく) → 7/8 と推移した。

### 部品ごとの検証 (すべて同じ乱数列で比較)

| 実験 | 結果 |
|---|---|
| 蹴りへの頑健化 | 学習中に蹴られた子は 1.0 m/s の蹴り 7 回で転倒 0 (普通に育った子は 2 回)。耐えられる強さは学習で見た強さまで (2.0 で育てると 2.0 まで無傷、2.5 で崖) |

## 講座のサンプル (Genesis の Go2 例題) との違い

出発点は Genesis 付属の `go2_env.py` / `go2_train.py` (平地で前に歩く強化学習の例題、101 反復) です。本提出で足したもの:

- 学習環境: 現場の地形 (3×3 区画)・横からの衝撃・旋回と低速の指令、転倒姿勢から始める起き上がり環境、報酬の再設計
- 司令役 (約 300 行): GPS もどき、A* 経路計画、高さスキャナ、転倒検知と復帰、足踏み・はまり込みからの脱出、人への確認と通報
- 認識: 頭のカメラ 8 方向 + ローカル VLM (Qwen3-VL-8B)
- 評価: 同じ乱数列での蹴り耐性・地形・任務の成績表、出来事の記録からの字幕生成

## 失敗と対処 (抜粋。詳しくはレポート)

- 報酬を 0 で切ると仰向けから抜け出せない → 連続値にしたら 4 姿勢とも起き上がった
- 「立っているときだけ姿勢を罰する」と閾値の手前 (上向き度 0.79) で止まる姿勢を覚えた (報酬ハッキング)
- 旋回の指令をゼロ固定で育てた子は曲がれず、経由地に向けなかった
- 通報の後、真後ろを向くときに GPS のばらつきで左右に迷い 4 分間足踏み → 回る向きを一度決めたら 90° を切るまで変えない
- 人形を砂利区画に置いたら地面が 0.4 m 高く、人形が埋まって見えなかった

## 動かし方

```bash
tools/install.sh                     # conda 環境 genesis (PyTorch は cu128 版に入れ直す。tools/ と README 末尾の注意を参照)
git clone https://github.com/Genesis-Embodied-AI/Genesis.git && cp src/*.py Genesis/examples/locomotion/
cd Genesis/examples/locomotion
python go2_train_site.py -e go2-site -b 4096 --max-iterations 1000            # 現場での歩行 (約 6 分, RTX 3090)
python go2_train_recover_site.py -e go2-recover-site2 -b 4096 --max-iterations 600   # 現場での起き上がり (約 5 分)
python mission.py --walk go2-site:999 --recover go2-recover-site2:599 --kick-at 40 --vlm --answer はい -o mission.mp4
python ../../../tools/make_mission_subs.py mission.mp4.events.json mission.srt   # 出来事の記録から字幕
```

VLM は `Qwen/Qwen3-VL-8B-Instruct` を transformers でローカル実行 (VRAM 約 17 GB)。`--vlm` を付けなければ写真判定なしで動きます。
人の返事は今は `--answer` の文字列 (音声は今後)。

## 実機への道筋

- 歩行・起き上がりの方策は 50 Hz の小さな MLP。観測は IMU と関節 (Unitree の学習環境と同じ並び)、出力は 12 関節の目標角 (PD: kp 20, kd 0.5) → Go2 EDU の低レベル API に薄い変換層で接続できる
- 本体の Jetson で歩行・司令役・VLM まで動く計算量。GPS は USB の GNSS 受信機で足す
- 実機前に要るもの: 摩擦・質量・遅延のランダム化、起き上がり時の自己衝突の確認、カメラの実画像での VLM の検証
